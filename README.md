# Remote Guard

Небольшое десктопное приложение для Windows (WPF / .NET 10) в стиле **Mining Switch** для быстрого отключения и включения удалённого доступа к ПК — например, перед стримом или игрой, чтобы никто случайно не подключился из сети.

## Установка

```powershell
powershell -c "irm https://raw.githubusercontent.com/XYphrodite/RemoteGuard/main/install.ps1 | iex"
```

Требуется [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (Windows x64).

## Что контролируется

- **Tailscale VPN** — при отключении выполняет `tailscale down` и останавливает службу `Tailscale`; при включении запускает службу и выполняет `tailscale up`.
- **OpenSSH (`sshd`)** — останавливает / запускает службу `sshd`.
- **Удалённый рабочий стол (`TermService`)** — останавливает зависимые службы (включая `UmRdpService`) и `TermService`; при включении запускает `TermService`.
- **AnyDesk** — останавливает службу `AnyDesk` и завершает процессы `AnyDesk.exe`; при включении запускает службу `AnyDesk`.

## Интерфейс

- **Слева** — карточка общего статуса и большая кнопка **«Выключить всё» / «Включить всё»**.
- **Справа** — отдельные тумблеры для каждой службы и актуальный статус.
- **Снизу** — журнал действий (логи) с кнопками **«Копировать»** и **«Очистить»**.
- **Трей** — иконка щита меняет цвет в зависимости от состояния (зелёный — доступ открыт, жёлтый — частично открыт, красный — всё заблокировано). Крестик сворачивает окно в трей.
